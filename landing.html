Disposable snap testing

Test the snap.
Leave no trace.

Telesnap is a narrow HTTP API for uploading an unsigned snap, exercising its configuration and services, and purging it automatically when its allotted lifetime ends.

Read the agent guide View the source
Input
Raw snap uploads up to 2 GiB
Boundary
Strict confinement only
Cleanup
Required lifetime, automatic purge
Built for isolation.

Telesnap controls snapd as root. Run it on a disposable Ubuntu test host, keep the bearer token private, and never treat an uploaded snap as trusted code.
